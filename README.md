# Proyecto_Arreglos: Sistema de Calificaciones

## Descripción
Programa que almacena las calificaciones de cinco estudiantes en un vector y permite consultarlas, modificarlas y calcular estadísticas.

## Objetivo
Aplicar arreglos (vectores), índices y ciclos en Python.

## Lenguaje utilizado
Python 3

## Funcionalidades
- Mostrar todas las calificaciones
- Consultar una calificación por índice
- Calcular promedio, nota más alta y más baja
- Contar aprobados y reprobados
- Modificar una calificación y mostrar el vector actualizado

## Instrucciones para ejecutar
1. Instalar Python 3.
2. Descargar el repositorio.
3. Abrir una terminal en la carpeta del proyecto.
4. Ejecutar: `python Main.py`
